Нужно что-то устанавливать?

Нет. Скачай файл .exe и запусти его. ZigZak Player — переносимое приложение для Windows 10 и 11, 64 бит.

Плеер работает без интернета?

Да. Музыка и видео воспроизводятся с твоего компьютера. Для прослушивания не нужен аккаунт или подключение к сети.

Какие файлы можно открыть?

MP3, MP4, FLAC, WAV, OGG, M4A и WebM. Воспроизведение отдельных файлов зависит от кодеков внутри них.

Что важно при первом запуске?

Версия 1.0.0 пока без цифровой подписи, поэтому Windows может показать предупреждение. Скачивай приложение по официальной ссылке на GitHub. Открыть страницу релиза ↗
