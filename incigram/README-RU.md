# InciGram / InciGram Desktop — первая версия исходников

Основа: https://github.com/AyuGram/AyuGramDesktop, ветка dev,
коммит 0f2a31bb420de98f331990432265b131b8d836b5.
Это модификация настоящего C++/Qt-клиента, использующего Telegram.
Собственного сервера сообщений здесь нет.

**Статус: исходники изменены, Windows .exe не собран и не проверен.**
Сборка и запуск на Windows, вход в Telegram, доставка сообщений,
звонки и поведение интерфейса при разных масштабах ещё требуют проверки.
Это первая визуальная переработка, а не завершённый редизайн всего приложения.

## Изменения приватности

Сохранение удалённых сообщений и истории правок включено по умолчанию.
Для новых профилей включены механизмы Ghost Mode AyuGram. Ранее сохранённые
настройки имеют приоритет. Это не делает Telegram анонимной сетью и не
восстанавливает версии, которые клиент не получил. Подробности в PRIVACY.md.

## Оформление

Новая светлая голубая палитра, просторные строки чатов, увеличенные отступы,
имя InciGram.exe и отдельная папка данных %APPDATA%/InciGram Desktop.
Автообновление из upstream и лишние внешние фоновые обращения отключены.

## Сборка Windows x64

Сначала прочитайте docs/building-win.md в этом архиве: оно задаёт версии
Visual Studio, MSVC, Windows SDK, Python и расположение библиотек именно
для скачанного коммита. Не используйте старую инструкцию building-win-x64.md
из README upstream: такого файла в этом коммите нет.

1. Распакуйте полные исходники как D:\TBuild\tdesktop. Создайте соседние
   папки D:\TBuild\Libraries и D:\TBuild\ThirdParty, как в инструкции upstream.
2. Установите инструменты из docs/building-win.md, откройте x64 developer
   PowerShell с нужной версией MSVC. Для стандартной поставки Visual Studio
   удобно использовать Launch-VsDevShell.ps1 -Arch amd64 -HostArch amd64;
   версию toolset выберите согласно инструкции upstream.
3. Получите собственные API ID и API hash на https://my.telegram.org.
   Задайте их **только локально** в переменных INCIGRAM_API_ID и INCIGRAM_API_HASH.
   Не отправляйте их в чат. API hash будет частью собранного клиента;
   пароль Telegram и коды входа в скрипт не вводятся.
4. Из developer PowerShell выполните:

   ./tdesktop/incigram/build-windows.ps1 -PrepareLibraries

   Подготовка библиотек upstream скачивает инструменты и зависимости;
   этот шаг ещё не запускался и не проверялся здесь. Повторная сборка с уже
   подготовленными библиотеками: ./tdesktop/incigram/build-windows.ps1.
5. Скрипт ожидает результат tdesktop/out/Debug/InciGram.exe. Это Debug-сборка,
   не готовый установщик. Windows-сборка может потребовать доработок после
   первого запуска компилятора. Не переименовывайте готовый AyuGram.exe:
   это не применит изменения исходников.
6. Входите в тестовый аккаунт через штатный экран Telegram; проверьте
   отправку в обе стороны, фото, уведомления, перезапуск, светлую/тёмную тему,
   масштаб 100/125/150/200%, архив, форумы, окно ошибок и значок панели задач.
   Проверьте сетевые обращения на Windows. До этих проверок не распространяйте
   сборку как проверенную.

Сборка не запускалась: среда Linux без Visual Studio/Windows SDK.
AGENTS.md upstream также предписывает избегать сборки проекта; здесь выполнены
проверки исходников и ресурсов. PowerShell-скрипт подготовлен, но не исполнялся.

## Тема без компиляции

InciGram-Cloud.tdesktop-theme можно открыть существующим Telegram Desktop или
AyuGram и применить как тему. Это меняет палитру и фон, но не размер строк,
набор кнопок, имя приложения или его поведение. Это не замена нашей сборке.

## Исходники и лицензия

Архив содержит снимки основного репозитория и всех рекурсивных подмодулей,
без Git-истории, бинарных зависимостей, Windows SDK и Qt из внешнего BuildPath.
Состав и закреплённые коммиты указаны в provenance.json.
lib-ui.patch сохраняет изменение палитры вложенной библиотеки; в полном
архиве оно уже применено. Не выполняйте git submodule update поверх этой
палитры без сохранения изменений.
